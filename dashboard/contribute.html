Benchmark your model

Compare a trading model or strategy against SPY using frozen market data. Run the open-source benchmark on your machine or in a notebook, then open this same dashboard with your results.

  1. Choose a modeluv run beatspy modelsInstall the model's dependencies or configure its API key if needed.
  2. Run a benchmark windowuv run beatspy run --model tpi-rs --scenario 2026-6mTPI-RS is a rule-based starting point that runs without an API key.
  3. Open your resultsuv run beatspy report --openCompare returns and inspect the trades, scores, and run artifacts.
