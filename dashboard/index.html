ONE WINDOW, THREE VERSIONS

How the six-month benchmark works

Every version starts April 6, 2026 with the same 100,000 simulated dollars, the same 24-stock and hedge universe, and the same frozen Yahoo prices, and is scored daily through October 2, 2026. Only the decision cadence changes, so the difference between them is the cost and value of trading itself. SPY is comparison-only and can never be bought. Results are replay-checked; the family is published comparison evidence and is not leaderboard-eligible.
