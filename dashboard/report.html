BeatSPY benchmark report

How trading models and strategies performed against SPY across the published protocol v2 windows.

How the benchmark works

  1. Freeze the market

    Each window uses a shared snapshot of adjusted prices. The 25-asset pool spans stocks and ETFs. Models use only data available at each weekly decision.

  2. Turn signals into trades

    Most runs convert stock-level outperformance probabilities into portfolio weights. The standard policy combines an equal-weight base with model tilts. HRP supplies its own weights.

  3. Score the portfolio

    Simulated fills use the next session’s open, with 5 basis points each for fees and slippage per trade leg. Excess return is the portfolio’s return minus SPY’s return, in percentage points.

Conclusion

The comparison changes with the market. Equal weight helps show what the fixed pool earned on its own. Momentum tests whether the models added value over a simple selection rule. Use the paired confidence interval on an individual run page to see how much uncertainty surrounds its gap to SPY.

Prediction quality adds a separate check. A model can rank stocks well while assigning unreliable probabilities. Read calibration and answer coverage alongside returns, especially when two results are close.

Forward evaluation would strengthen the evidence. The published runs use historical prices and a fixed asset pool chosen after the fact. Freezing the model versions, inputs, universe, and rules before a new period starts would test whether the observed patterns persist.
